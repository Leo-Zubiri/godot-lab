# tasks/exploration/ — free-form discovery tasks

Open-ended Godot questions and investigations (web allowed). Exploration **generates candidate findings** for
`../../knowledge-outbox/` and **makes no measured-improvement claims**.

An exploration finding may *seed* a `godot-knowledge` note later. To avoid benchmark leakage, record which notes a task
contributed to (`contributes_to_notes`); such a note may be benchmarked only on **holdout** tasks that did not
contribute to it.
